# Tax Consultancy Website

A professional website for Tax Compliance Chiefs Zimbabwe, built with HTML and CSS.

## Project Overview
This is a responsive website for a tax consultancy firm, featuring:
- Homepage with services
- Contact information
- Company vision and values
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (basic)
- Git & GitHub

## Features
- Responsive navigation
-  Services section
- Contact form
- Modern design

## How to View
1. Clone repository: `git clone https://github.com/DADISO203/TCC-WEB.git`
2. Open `index.html` in browser
